To be admitted to the exam, you must successfully complete **five of the six** lab submission units listed below. Each unit is documented in a written report, submitted by its deadline.

The lab work itself is what matters: the report is how you prove you did it, and it doubles as practice in documenting technical work clearly - a core skill in this field.

## Submission units
The eight labs in the course are grouped into submission units. Some labs are combined, one lab is split, and two labs are optional and do not count toward admission.

| Unit | Covers | Deadline |
|---|---|---|
| Recon | Reconnaissance lab | 11 Nov 2026 |
| Web I | Web lab - file inclusion & file upload | 25 Nov 2026 |
| Web II | Web lab - command injection & SQL injection | 9 Dec 2026 |
| Public Exploits & Passwords | Public Exploits lab + Passwords lab | 23 Dec 2026 |
| LPE | Linux Privilege Escalation lab | 13 Jan 2027 |
| Pivoting | Pivoting lab | 20 Jan 2027 |

All deadlines are **23:59** on the stated day. You complete **five of these six** units for admission.

> The **Bash** lab and the **Web Frameworks** lab are **optional**. They are worth doing (Bash to get comfortable with the environment and the basics, Web Frameworks because it's an interesting topic) but neither counts as a submission unit, and neither is required for admission.
